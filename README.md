# Lectrail — 發行物

這裡只放 **Lectrail 的安裝檔與更新清單**，不含原始碼。

Lectrail 把課程錄音與投影片整理成可以複習的筆記：章節敘事為主，投影片、逐字稿、
原始錄音都從內容連出去。點一下段落，就會從老師講到那裡的時間開始播放。

- **轉錄在你自己的電腦上跑**，錄音檔不會離開那台機器。
- 只有送去整理章節的文字，會經過使用者自己設定的 LLM。

## 下載

到 [Releases](../../releases) 取最新的 `.dmg`。需要 Apple Silicon 的 Mac。

每個版本都會附 SHA-256，建議核對：

```
shasum -a 256 Lectrail-<版本>.dmg
```

## 第一次打開會被系統擋下來

這個 App 沒有經過 Apple 公證，所以 macOS 預設不讓它執行。安裝步驟與處理方式寫在
隨附的安裝說明裡，DMG 內也有一份。

## 這個 repo 裡有什麼

| 檔案 | 用途 |
|---|---|
| `appcast.xml` | 自動更新的清單，App 會定期讀它 |
| Releases 的 `.dmg` | 安裝檔 |

## 回報問題

App 內「Lectrail → 回報問題…」會產生一份只含診斷資訊的報告（**不含**課程內容、
逐字稿或錄音），存檔後可以附在 issue 裡。
